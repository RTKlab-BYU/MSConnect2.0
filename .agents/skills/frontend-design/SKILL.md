# MSConnect frontend design

Use this guidance when building or redesigning the MSConnect web interface.

- Start from the researcher’s task and the lab workflow; make run state, QC integrity, and the next action easy to scan.
- Prefer a quiet scientific operations aesthetic: clear typography, restrained color, compact rectangular controls, and decoration only when it carries meaning.
- Keep project navigation persistent but subordinate to the selected lifecycle page. Avoid oversized heroes, rounded-card grids, gradient washes, and decorative labels.
- Design around the actual viewport. Preserve legible tables with responsive columns, wrapping, search, or pagination; never introduce page-level horizontal overflow.
- Make status distinctions understandable without color alone, retain visible keyboard focus, and respect reduced-motion preferences.
- Before handoff, review the page against the brief at desktop and narrow widths; remove any element that adds visual weight without helping a user decide or act.
